# Test assets for the avatar/lip-sync tests (19-22)

Not committed (they're binary media, not code) — used by `test_19`
through `test_22` as the source face / driving material.

**No real person's likeness is used here on purpose.** These are each
model repo's own officially bundled demo asset, copied in for pipeline
testing only — not a photo of the project owner or any other real,
identifiable individual:

| File | Source | Used by | Why this one |
|------|--------|---------|--------------|
| `source_face.jpg` | `MuseTalk/assets/demo/monalisa/monalisa.png` | Wav2Lip, SadTalker, LivePortrait | The Mona Lisa — public-domain painting, no living person involved |
| `source_face.mp4` | `MuseTalk/data/video/yongen.mp4` | MuseTalk (needs a video, not a photo) | MuseTalk's own bundled inference demo clip |
| `driving_video.mp4` | `LivePortrait/assets/examples/driving/d0.mp4` | LivePortrait only | LivePortrait's own bundled driving example — the motion that gets copied onto `source_face.jpg`. LivePortrait doesn't take audio directly, see `test_21`'s docstring |

If you'd rather swap in a specific photo later, replace these files
directly — just avoid photos of real, identifiable people who haven't
consented to appearing in lip-sync output.

Driving audio is shared across tests 19, 20, and 22 — they reuse
`text_to_speech/tts_output/round_2.wav`, generated by running
`text_to_speech/test_09_tts_kokoro.py` once.
